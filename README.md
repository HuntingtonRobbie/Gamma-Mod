# Gamma-Mod

A small client-side Fabric mod for Minecraft 26.3. It is written from scratch for personal use.

## What it does
- A key (default **K**, rebindable under Controls) turns full bright on and off.
- Full bright is a client-side Night Vision effect with no particles and no icon. It is applied again after respawning or changing dimension while it is on.
- Only needed on the client: no server install.

## Building
Java 25 and the Gradle wrapper: `./gradlew build`. The jar is in `build/libs/`.
